# Mobile Test Automation Framework Appium Java

This repository contains a **mobile automation framework built using Appium and Java**.  
It demonstrates **SDET-level automation skills** for testing **Android and iOS applications**, including gestures, device interactions, and real mobile app scenarios.

---

## Tech Stack

- Java  
- Appium  
- Maven  
- TestNG  
- Eclipse IDE  
- Git & GitHub  

Platforms:
- Android
- iOS

## Automation Scenarios Covered

- Appium server start and stop programmatically  
- Android and iOS driver management  
- UI element handling (buttons, text fields, switches)  
- Radio buttons and checkboxes  
- SeekBar handling  
- Swipe gestures  
- Drag and drop actions  
- Scroll using executeScript  
- Screenshot capture  
- Calculator app automation  
- Contacts app automation  
- End-to-end mobile app flows  

---

## How to Run

1. Clone the repository

   git clone https://github.com/ArpitChoubey/Appium-eclipse-workspace.git

2. Import the project into Eclipse as a Maven project

3. Start Appium Server (manually or via AppiumServerManager)

4. Connect Android Emulator or Real Device

5. Run test classes using TestNG
